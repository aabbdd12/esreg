# Replication — Endogenous Switching Regression with Heterogeneous Selection on Gains

Araar, A. (2026). *Endogenous Switching Regression with Heterogeneous Selection
on Gains: Assumptions, Tests, and Estimation.* Zenodo.
<https://doi.org/10.5281/zenodo.22717029> — version of October 2026, with
`esreg` 1.0.0.

Every table and figure of the paper is reproduced here, in Python and in Stata,
from the same data. The paths quoted in the paper are relative to this folder.

## Layout

```
data/      the samples: esr_sim, esr_annex2, esr_skew, esr_nonlin (Araar 2026a, b);
           esr_kx, esr_suff, esr_dh, esr_link, esr_wt (this paper: generated by the
           export scripts of python/, seed 2026); union3, drugexp (Stata Press)
python/    esreg/: the reference library (likelihood, fiml, twostep, effects, tests, diag, api)
           validate_esreg.py, check_score.py, smoke_het.py: checks of the library
           mc_common.py: the designs of Araar (2026a); esr_fiml_reference.py
           mc_spec.py, mc_kappa_x.py, mc_sufficiency.py, mc_strength.py, mc_normal.py:
             the Monte Carlo of the tests (outputs mc_*.txt); mc_pdid.py (not reported)
           export_*.py: the samples of this paper and their reference values (*.txt)
stata/     sec7_union3.do: Section 7
tests/     the do-files that check the commands and their standard errors;
           mc/: the Monte Carlo of the standard errors, raw results in mc/out/;
           bruteforce/: the brute-force influence functions, outputs in bruteforce/out/
paper/     esreg.tex and the figures of Section 7 (the compiled paper is ../paper/esreg.pdf)
logs/      the logs of the do-files, run from this folder (StataNow 19, Windows)
```

The do-files load the commands from `../src/`, the package of this repository at
the same version, not from an installed copy.

## How to reproduce

Stata 16 or later, from this folder (`cd .../esreg/replication`):

```stata
do stata/sec7_union3.do       // Section 7: writes paper/fig_union3_*.pdf and paper/reading_union3.txt
do tests/esrtest_test.do      // Section 4: the tests on the samples of the paper
do tests/esrdiag_test.do      // Section 4.4: strength and support
do tests/esreg_test.do        // Section 8.4: against the Python library, movestay and msat
do tests/etregress_check.do   // Section 8.4: against etregress
do tests/test_effects_se.do   // Section 8.4: the standard errors against oracles (pass/fail summary)
do tests/esreg_wt_test.do     // Section 8.3: weights, hsize() and the survey design
do tests/mc/mc_summary.do N   // Section 6: Monte Carlo of the standard errors (also K)
do tests/mc/mc_summary.do AC  // Section 5.3: the augmented two-step (also AN; AC r1, AN r1)
```

The two `mc_summary.do` lines read the stored replications of `tests/mc/out/`.
`tests/mc/mc_se.do <design> <first> <last> <n>` and `tests/mc/mc_aug.do <design>
<first> <last> <n> [routes]` regenerate them, one seed per replication, so that
blocks run in parallel processes give the same results (the stored blocks:
`mc_N_1`, `mc_N_1668`, `mc_N_3335`, `mc_K_1`, n = 2,000; `mc_AN_1`, `mc_AN_1001`,
`mc_AC_1`, `mc_AC_1001` and their `-r1` routes). The files of
`tests/bruteforce/` regenerate the brute force (`bf.do`, `bf2.do`) and the
influence functions of the code (`ifexact.do`, `ifcode.do`; see
`tests/bruteforce/README.md`).

Python (3.10 or later, `pip install -r python/requirements.txt`), from `python/`:

```
python validate_esreg.py          # the library against movestay and msat           (validate_esreg.txt)
python mc_spec.py 200             # Table 2, specification of the selection equation   (mc_spec.txt)
python mc_kappa_x.py 200          # Table 2, constant kappa                             (mc_kappa_x.txt)
python mc_sufficiency.py 200      # Table 2, index sufficiency                          (mc_sufficiency.txt)
python mc_strength.py 100         # Table 2, strength                                   (mc_strength.txt)
python mc_normal.py 100           # Table 2, normality by regime                        (mc_normal.txt)
python export_link.py             # data/esr_link.dta and its reference values; also export_kx, export_suff, export_wt
```

## Mapping to the paper

| Paper | Produced by |
|---|---|
| Table 2 (Monte Carlo of the tests) | `python/mc_*.py` → `python/mc_*.txt` |
| Monte Carlo of the standard errors (end of Section 6) | `tests/mc/mc_se.do`, `tests/mc/mc_summary.do N` and `K` |
| The augmented two-step (Section 5.3) | `tests/mc/mc_aug.do`, `tests/mc/mc_summary.do AN` and `AC` |
| Values quoted in Section 4 | `tests/esrtest_test.do`, `tests/esrdiag_test.do`, `python/export_*` |
| Tables 3–6, Figure 1 (Section 7) | `stata/sec7_union3.do` → `logs/sec7_union3.log`, `paper/fig_union3_*.pdf`, `paper/reading_union3.txt` |
| Weights and survey design (Section 8.3) | `tests/esreg_wt_test.do`, `python/export_wt.txt` |
| Validation (Section 8.4) | `tests/esreg_test.do`, `python/validate_esreg.py`, `tests/etregress_check.do`, `tests/test_effects_se.do` with `tests/bruteforce/` |
